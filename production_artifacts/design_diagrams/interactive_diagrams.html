📅 EVENT
  • # id: UUID [PK]
  • • titre: VARCHAR
  • • date_debut, date_fin: TIMESTAMP
  • • type_portee: ORGANISATION | TEAM
  • • team_id: UUID [FK -> TEAM]
  • • created_by_id: UUID [FK -> USER]
📝 EVENT_ATTENDANCE
  • # id: UUID [PK]
  • • event_id: UUID [FK -> EVENT]
  • • participant_id: UUID [FK -> PARTICIPANT]
  • • statut_presence: PRESENT | ABSENT
  • • checked_at: TIMESTAMP
  • • checked_by_id: UUID [FK -> USER]
🌸 PARTICIPANT (Bloomer)
  • # id: UUID [PK]
  • • nom, prenom: VARCHAR
  • • photo_url: VARCHAR [Badge/Billet]
  • • team_id: UUID [FK -> TEAM]
event ( id, titre, description, date_debut, date_fin, lieu, type_portee, team_id#, created_by_id#, created_at )
